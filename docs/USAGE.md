# Using the course

Open the approved course website in a browser. Loopback preview is for the development device. A future workplace host needs organizational approval.

1. Read and acknowledge the privacy boundary. Leave remembering off on a shared device.
2. Read a lesson's briefing, objectives, and references. Earlier lessons are suggested preparation; all can be revisited.
3. Choose a token group and token, then add it. Insert at a chosen position or use edit/reorder to move or remove tokens. Native selects support keyboard selection; the course has no real-value entry.
4. Check query. Supported syntax/catalog, whole Boolean filter intent, and pipeline structure are scored separately. Wrong roles and broad ORs cannot gain full query credit. Unsupported course syntax is not a Google compiler verdict.
5. Answer both method questions and check method. Query 70 plus method 20 gives symbolic mastery.
6. Reveal hints as needed. Hint 3 reveals and can load a worked solution, without penalty. Scores are practice feedback rather than independent testing.
7. If authorized, open workplace SecOps manually. Copy the synthetic query if useful, substitute values only there, and follow the private steps. Return no data or observations. Acknowledge execution/review only after doing them. Unavailable capability leaves practice pending.

Practice boxes enable only at query 70. Each shows five transient points; both are required to save ten. An executed zero-result query may qualify after reviewing its limitations. The course never verifies execution.

Editing tokens clears the current assessment and acknowledgments. Leaving the challenge clears attempt inputs too. Saved best scores keep components from one attempt; highest hint use merges separately. Reloading clears session-only scores. Optional remembering saves only the strict projection. Clear progress removes this course's key and memory without affecting other courses.

Reference links explicitly open fixed public HTTPS pages. Copy is write-only; if blocked, select the read-only preview and copy manually. Approved workplace Copilot remains separate under organizational policy.
