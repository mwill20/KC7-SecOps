# Using the course

Open [KC7 SecOps](https://mwill20.github.io/KC7-SecOps/) in a browser. No install, account or terminal is needed. At work, use it only if your organization permits the site and optional browser storage. Loopback preview is for developers.

1. Read and acknowledge the privacy boundary. Leave remembering off on a shared device.
2. Choose Start the case. The first chapter shows a complete query and explains each part before you start mission 01.
3. Read the story and query explanation. Early examples are complete; later starters have marked blanks. Type/paste the training query or use Help me fill the blanks. Keep the supplied placeholders here; choose real work values only in SecOps.
4. Check query. Supported syntax/catalog, whole Boolean filter intent, and pipeline structure are scored separately. Wrong roles and broad ORs cannot gain full query credit. Unsupported course syntax is not a Google compiler verdict.
5. Answer both method questions and check method. Query 70 plus method 20 gives symbolic mastery.
6. Reveal hints as needed. Hint 3 reveals and can load a worked solution, without penalty. Scores are practice feedback rather than independent testing.
7. If authorized, open workplace SecOps manually. Copy the synthetic query if useful, substitute values only there, and follow the private steps. Return no data or observations. Acknowledge execution/review only after doing them. Unavailable capability leaves practice pending.

Practice boxes enable only at query 70. Each shows five transient points; both are required to save ten. An executed zero-result query may qualify after reviewing its limitations. The course never verifies execution.

Editing query text clears the current assessment and acknowledgments. Leaving the challenge clears attempt inputs too. Saved best scores keep components from one attempt; highest hint use merges separately. Reloading clears session-only scores. Optional remembering saves only the strict projection. Clear progress removes this course's key and memory without affecting other courses.

Reference links explicitly open fixed public HTTPS pages. Copy is write-only; if blocked, select the query text or example and copy manually. Approved workplace Copilot remains separate under organizational policy.
