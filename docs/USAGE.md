# Using the course

Open [KC7 SecOps](https://mwill20.github.io/KC7-SecOps/) in a browser. No install, account or terminal. Workplace website/storage/transfer approval remains separate.

1. Read the privacy boundary. Leave remembering off on a shared device.
2. Choose Start the case. Read the story, complete query and explanation before trying it.
3. Type/paste only the training query and supplied placeholders, or use the guided blanks. Choose real values only inside workplace SecOps.
4. Check query. Supported syntax, filter intent and pipeline structure score up to 70. Unsupported course syntax is not a Google compiler verdict.
5. Answer the two method questions and check method for 20. With query 70 and method 20, the course awards 10 completion points and displays Mission complete.
6. Reveal hints whenever useful. The last reveals a worked solution; there is no penalty.
7. Run the query in authorized workplace SecOps if available, substituting values only there. Keep all observations/output there. This is not measured by the course.

Changing the query resets the current assessment/method choices; leaving the mission clears its inputs. Saved best uses one attempt, not mixed components. Optional remembering stores only IDs/versions/scores/completion/hints. Turning it off removes current v2 progress only; Clear progress removes this course's v1/v2 progress, never feedback. Old v1 practice records are preserved until Clear and are not converted to the revised scoring.

## Feedback and screenshots

Select Feedback & ideas on any page. Add a comment and optionally paste a reviewed still PNG/JPEG/WebP into the box. Save feedback in this browser keeps it on this device/profile. Export saved feedback downloads a JSON file with images; Export draft works even when storage is unavailable. Attach the reviewed export at home after an employer-permitted transfer. Nothing is sent or synchronized automatically; no destination has been selected.

Images retain encoded metadata; there is no automatic redaction. Delete saved entries individually after confirmation. Clearing site data can erase feedback; Clear progress does not. See [feedback](FEEDBACK.md) for limits and [privacy](PRIVACY.md) for exact data flows.

Fixed documentation links open only on click. Query Copy is write-only; if blocked, copy manually. Workplace Copilot is optional and separate under organizational policy.
