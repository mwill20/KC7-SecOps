- Supplied queries first; partly completed starters next; independent construction later. New concepts still receive an example when introduced. References and limitations are available without dominating the opening screen.
- Preserve deterministic AST/whole-filter/pipeline evaluation and 70 query / 20 method / 10 self-attested practice. Method questions test fixed choices, never workplace observations. Practice remains optional and honestly self-attested.
- Owner selected a training-query text editor after disclosure of accidental real-value entry risk. Implement placeholders-only grading, transient query state and preset gap help; no query persistence/transmission. A managed device does not make this external origin employer-approved.

## Accuracy and boundary

Search uses real UDM field paths, not a renamed KC7 Employees table. `principal.user.title` is a documented job-title field; its population depends on source/enrichment. Recorded titles are neither permission roles nor proof of a person's historical title at login time. Missing titles are a coverage limitation. `USER_LOGIN` includes attempts; the successful-user count also filters `ALLOW`. Failure counts use `FAIL`, not a guessed vendor status. Time range is selected separately in SecOps.

New parser support is bounded to documented distinct-user counting and job-title grouping. No arbitrary field/literal/function support, SIEM integration, runtime AI, external runtime dependency or result grading is introduced. Template explanations and all reference/alternate/hint queries must validate against the same real parser used by the course.
