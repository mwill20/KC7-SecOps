# Limits and appropriate use

- Symbolic grading is not Google compilation, SIEM execution, result validation, attack detection, or certification. The bounded AST model conservatively rejects some valid platform queries.
- No logs/events are supplied. Equivalence truth assignments are abstract predicate combinations, not synthetic telemetry.
- Mapping, normalization, case, time range, permissions, ingestion latency and features require private tenant checks. The UDM dictionary does not prove field population.
- L06 tumbling windows are preview/pre-GA, potentially region/customer dependent. Do not enable previews for this course. Missing capability leaves practice pending.
- Hints reveal solutions without penalty. Method points prove fixed selections. Execution flags are self-attested; storage is editable. Scores have no compliance/authorization value.
- Closed choices prevent supported entry of workplace data; they cannot constrain browser-owner code/DOM changes, a compromised release, or extensions. Same-origin scripts may inspect local state. Use a dedicated approved origin.
- The host can log ordinary HTTP metadata. Private source is separate from website audience. Meta CSP cannot enforce frame-ancestors; hosting headers must provide framing protection.
- Automated browser tests and screenshot/keyboard checks are builder evidence. Full manual screen-reader/200% browser zoom checks, independent review, tenant pilot and deployment smoke testing remain separate checks.
- There is no production host, monitoring, account system, backend, synchronization, export/import, or workplace installation. Those are outside scope.
