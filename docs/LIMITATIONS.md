# Limits and appropriate use

- Symbolic grading is not Google compilation, SIEM execution, result validation, attack detection, or certification. The bounded AST model conservatively rejects some valid platform queries.
- No logs/events are supplied. Equivalence truth assignments are abstract predicate combinations, not synthetic telemetry.
- Mapping, normalization, case, time range, permissions, ingestion latency and features require private tenant checks. The UDM dictionary does not prove field population.
- L06 tumbling windows are preview/pre-GA, potentially region/customer dependent. Do not enable previews for this course. Missing capability limits private practice; it does not block course completion.
- Hints reveal solutions without penalty. Method points prove fixed selections. Completion means course checks passed, not workplace execution; storage is editable. Scores have no compliance/authorization value.
- The owner-approved query textarea can receive accidental workplace text. Only catalog placeholders are supported for grading. App code does not persist/transmit query text, but cannot constrain browser features, extensions, same-origin code or a compromised release. A managed device does not make a public origin internal. Same-origin scripts may inspect local state. Use a dedicated approved origin.
- The host can log ordinary HTTP metadata. Private source is separate from website audience. Meta CSP cannot enforce frame-ancestors; hosting headers must provide framing protection.
- Automated browser tests and screenshot/keyboard checks are partial accessibility evidence. Independent review reports bind their specific artifacts; current feedback/export review is recorded separately; full manual screen-reader/200% browser zoom, tenant pilot and actual deployment/browser evidence are distinguished in IMPLEMENTATION_STATUS.md and DEPLOYMENT.md.
- The owner approved public GitHub Pages. Host status and HTTPS are managed by GitHub; there is no application backend, visitor monitoring, account system, synchronization or import. Separate feedback can be exported as a local JSON file or workplace installation. Publishing does not make the course employer-approved or tenant-compiled.

- Explicit feedback saves comments and manually pasted images in local IndexedDB. No automatic upload or cross-device retrieval. Different browsers require a permitted file transfer. Original image metadata remains; no DLP, redaction, encryption or guaranteed backup. Shared-origin scripts/extensions/profile access can expose local data. See FEEDBACK.md.
